# 数字小英雄 🌟

**正式地址：https://edliu1105.github.io/number-heroes/**

给 3–4 岁中文小朋友的数学理解启蒙乐园——不是背诵，是真正理解数字、数量和加法。

孙悟空、葫芦娃、复仇者（含蜘蛛侠、迈尔斯、格温）、汪汪队、Bluey、小猪佩奇——39 位小伙伴住在云上六座欢乐岛，等孩子来帮忙"数一数"。

## 教学核心

打通三种表征的连接：**实物数量 ↔ 数词（口语"三"）↔ 数字符号（3）**，再在数量上做操作（合起来/比多少）。

七种活动，对应七项技能，自适应难度（1–3 → 1–5 → 1–10）：

| 活动 | 技能 |
|---|---|
| 数一数 | 一一对应 + 基数原则 |
| 找数字 | 数量/数词 → 数字符号 |
| 喂一喂 | 按数取物（生产性任务，主动提交） |
| 闪一闪 | 感数（1–4 一眼识数） |
| 谁的多 | 数量比较 |
| 合起来 | 合成——加法的概念本体 |
| 来了几个 | 加法故事（先数全体） |

## 技术

- 单 `index.html` + `assets/`，vanilla JS，零依赖，PWA 离线完整可玩
- 全程中文语音（Web Speech API），针对 iPad WebKit 的完整军规实现（手势解锁/安全打断/事件优先+超时兜底/计数词有序通道/无声检测）
- 全部美术素材由 GPT Image 2 生成（512px 量化优化，总量 ~4.2MB）
- Playwright 八组自动化测试为发布门槛（全流程/语音时间线/慢TTS排空/连点压力/离线整岛/WebKit 横竖屏七活动矩阵/运动命中）

## 本地运行

```bash
python -m http.server 8137

```

## 测试

```bash

```

## 更新方法

改代码 → push 到 main → iPad 上刷新一次页面即生效（页面网络优先策略，素材缓存优先）。

## 家长功能

地图右下角齿轮**长按 3 秒**：学习进度、难度档位、语音诊断（iPad 无声排查）、减少动画、重置。
