9: ## 1. 教学设计（为什么这样教）
10: 
11: ### 1.1 "理解"的操作性定义
12: 
13: 对这个年龄段，"理解数学"= 打通三种表征之间的双向连接，并能对数量做操作：
14: 
15: ```
16:    实物数量 (●●●)  ←→  数词 (口语"三")  ←→  数字符号 (3)
17:                  ↘        操作        ↙
18:               合起来(加) / 比多少 / 分开
19: ```
20: 
21: 发展心理学上的关键里程碑（Gelman & Gallistel 计数五原则、CRA 教学法）：
22: 
23: 1. **一一对应**：数一个碰一个，不重不漏。
24: 2. **基数原则**：数到最后一个数词 = 这堆东西的总数（孩子最容易缺的一环：数完 1-2-3，问"一共几个"却答不出）。
25: 3. **感数 (subitizing)**：1–4 个不用数、一眼看出，是数感的地基（"闪一闪"活动）。
26: 4. **按数取物**：给我 3 个——比"数现成的"更高一级的生产性任务（自由喂 + 主动提交判定）。
27: 5. **合成**：5 是 2 和 3 合起来的——这就是加法的**概念本体**；先有"合起来"，再有"+"（本版只做正向合成，分解与守恒记为后续方向）。
28: 6. **加法即合并再数**：情境故事（来了 2 个，又来了 2 个）→ 全部点数 → 说总数。

31: 
32: - **零文字依赖**：所有指令语音播报；数字符号本身是教学内容，出现时必伴随语音。

159: ## 9. v3 修订（吸收第二轮审查 B1/B2/B3 与 A 节未闭合项）
160: 
161: ### 9.1 教学测量契约（T2/T4/T5）
162: 
163: - **结果分级**：每个活动返回 `outcome ∈ {independent, hinted}`。`independent` = 首次作答/首次提交即正确且未触发任何**脚手架**；其余一律 `hinted`（示范后完成永不计独立掌握）。
164: - **脚手架的定义**：会传递解信息或演示操作的介入——幽灵手指点/示范回合/正确牌脉冲/示范点数。**逐字重播当前指令**（第一次空闲提醒、重听按钮）属于无障碍重复：不含任何解信息，不降级 outcome。第二次空闲提醒必附幽灵手指点，故必置 assisted。
165: - **升降级**：`independent` → `up++`（3 连升一级, wins++）；`hinted` → `up=0, down++`（2 连降一级）。等级范围 1–3, 由 `Skills` 单点实现。原"70/20/10"表述废弃, 替换为实现规则：每次会话 = 1 题热身点数 + 4 题按 `wins+随机扰动` 升序加权选择（练得少的优先）, 相邻不重复, 未解锁类型不入池。
166: - **先修门槛**：`count/numeral` 常开；`produce/flash` 需 count 独立完成≥2 次；`compare/compose` 需 count 等级≥2；`add` 需 compose 独立完成≥2 次。数字范围升级即技能内等级(1-3), 由连对驱动。
167: - **教学题 vs 探测题**（T4）：点数/加法中, 计数徽章在**提问时刻淡出**——基数答案必须来自"最后一个数词"的记忆而非抄读屏幕数字。答错后的示范会重建视觉支持（此题已降级为 hinted）。
168: - **脚手架阶梯**（T5）：错 1 次 → 朗读所选数字 + 完整示范点数 + 重问；错 ≥2 次 → 示范后正确数字牌脉冲提示。喂一喂：错 1 次 → 数"已吃的"对照目标 + 复位重试；错 2 次 → 幽灵手示范喂正确数量。

170: ### 9.2 活动规格修订
171: 
172: - **喂一喂 = 真按数取物**（P0-T1）：自由喂（可少可多, 盘中 m>n）, 孩子**主动按绿勾提交**；提交时恰好 n 才成功。首次提交正确 = independent。绿勾在第一次喂食后出现（防误触）, 语音+幽灵手介绍它。L3 隐藏点阵只留数字符号（记忆负载升级）。
173: - **闪一闪（新, 感数）**（T3）：骰面式稳定点位呈现 1–4 个物品 1.2–1.6s → 云朵盖住 → 选数字牌。错误脚手架 = 掀云重数再盖。守恒任务本版不实现, 从教学声明中移除（记为后续方向）。
174: - **找数字**：目标以**点阵提示卡**（五格框排布）+ 语音双通道给出（P0-U1）——无声环境下孩子仍可"数点点→找数字", 且把任务升级为数量→符号链接。
175: - **合起来**：仅正向合成（指定两组→合并→报总数）；"分解"变体从本版声明中移除（T6）。加法句式在 add 活动成功反馈中引入（"X 加上 Y, 一共是 Z"）。
176: - **谁的多**：本版只教"多"（不出现相等）；两盘同物品、同尺寸、同网格排布, 差异仅数量（T8）。
