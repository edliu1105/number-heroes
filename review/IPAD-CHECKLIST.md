# 真机 iPad 冒烟清单（家长执行，约 5 分钟）

上线后请在孩子的 iPad 上过一遍。任何一条不符，把现象发我即可。

## A. 声音（最重要）
1. Safari 打开正式网址 → 点大大的"开始玩" → **应立刻听到欢迎语**（中文女声）。
2. 若听不到：看顶部是否出现黄色"听不到声音？"条 → 点它 → 仍无声则检查侧边静音拨片与音量。
3. 把侧边静音拨片打开（静音状态）→ 重新进入 → 点开始 → 是否仍有声音（无声保活音频的绕过效果，如无声请记录）。
4. 玩"数一数"：慢慢逐个点物品，应逐个念"一、二、三…"；快速连点不应重叠混音。
5. 左下角 🔊 按钮：点击应重播当前指令。
6. 按 Home 出去再回来 → 声音应恢复（再点一次任意物品）。

## B. 加主屏（PWA）
1. Safari 分享按钮 → "添加到主屏幕" → 桌面出现"数字小英雄"图标（孙悟空+星星）。
2. 从主屏图标打开（全屏无地址栏）→ 点开始 → 有声音、可玩。
3. 开飞行模式 → 从主屏重新打开 → **完整可玩**（图片齐全、可进岛完成活动）。
4. 关飞行模式。

## C. 交互
1. 横屏、竖屏各玩一个岛，布局无遮挡、按钮都点得到。
2. 双指捏合/双击屏幕：页面不应缩放。
3. 长按角色图片：不应弹出系统菜单。
4. 左上角🏠：按一下不退出（有语音提示），2.6 秒内按第二下才回地图。
5. 右下角齿轮长按 3 秒：家长面板打开；里面"测试发声"有声音；关闭按钮正常。

## D. 更新验证（改版后用）
1. 我 push 新版后：iPad 上刷新一次页面（或杀掉 PWA 重开两次）→ 家长面板版本号应变化。
